# TeriCraft

TeriCraft is a 2D sandbox game prototype built with React, Vite, and HTML5 Canvas.

The project explores core sandbox gameplay mechanics such as world generation, mining, building, inventory management, and player interaction within a browser-based environment.

## 🚀 Features
*   **Procedural World Generation:** Unique landscapes every time you play.
*   **Interactive Terrain:** Seamless block mining and placement.
*   **Layering System:** Support for both foreground and background blocks.
*   **Inventory & Hotbar:** Intuitive resource management.
*   **Performance:** Real-time rendering optimized via HTML5 Canvas.

## 🛠️ Tech Stack
*   **Framework:** React
*   **Build Tool:** Vite
*   **Language:** JavaScript
*   **Graphics:** HTML5 Canvas
